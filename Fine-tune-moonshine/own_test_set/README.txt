  ...

- Short pieces, about 5-20 s each (one or two sentences). Longer files work too (transcribed in 20 s chunks).
- Any audio format: wav, mp3, m4a, flac, ogg. 8 kHz is fine.
- Write the text the way you want the model to write it: numbers as words, English words in Bangla script.
- Mix city and regional callers, inbound and outbound. ~1-2 hours total is a good start.
- Fastest way to make the .txt files: let the current model transcribe, then correct the text by hand.
